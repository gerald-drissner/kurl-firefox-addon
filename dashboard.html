kURL Helper for YOURLS

The optional server-side plugin adds lookup, editing, regeneration and remote deletion. It is installed on YOURLS, not your browser.

Optional
Installation guide and download
  1. Download plugin.php here or copy the full PHP source code below.
  2. On your YOURLS server create user/plugins/kurl-helper/ and save plugin.php in that folder (not plugin.php.txt).
  3. In YOURLS → Manage Plugins, activate kURL Helper.
  4. Return to this dashboard and click Refresh. Version 1.1.6 or newer enables advanced actions.
